# BLACK RUSSIA — 2D мини-игра

Фанатская браузерная мини-игра по мотивам BLACK RUSSIA: ночной открытый город, заказы такси, угоны, полиция и погони.

> 18+ · Фанатский проект. Не связан с оригинальной игрой и её правообладателями.
>
> 🤖 Проект создан с помощью ИИ.

## Запуск

**Способ 1 — просто открыть файл**

Откройте `index.html` в современном браузере (Chrome, Edge, Firefox или Safari).

**Способ 2 — локальный сервер (рекомендуется)**

Из папки `black-russia` выполните:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

Сервер удобнее для стабильной работы сохранений в браузере. Внешние библиотеки и ассеты не используются — игра работает полностью локально.

## Управление

### Пешком

| Клавиши | Действие |
| --- | --- |
| `WASD` / стрелки | движение |
| `Shift` | бег |
| `E` | сесть в машину / взаимодействие / взять заказ |

### За рулём

| Клавиши | Действие |
| --- | --- |
| `W` | газ |
| `S` | задний ход / торможение |
| `A`, `D` | руль |
| `Space` | ручник |
| `E` | выйти из машины |

`Esc` — пауза, сохранение и статистика.

### Телефон и планшет

На сенсорных устройствах автоматически появляются экранные кнопки:

- джойстик слева — движение и руль;
- кнопка **E** — действие;
- кнопка с рукой — ручник.

## Как играть

- **Такси** — бирюзовый маркер `Т` у гаража. Возьмите заказ, подберите клиента на машине и отвезите его к маркеру. Останавливайтесь рядом с клиентом, чтобы он сел.
- **Угон** — оранжевый маркер `У`. Найдите отмеченную на карте машину, угоняйте её и доставьте в зелёную зону `ГАРАЖ`. Чем целее машина, тем выше оплата.
- **Деньги** — зелёные купюры на улицах, оплата заказов. При задержании часть денег уходит на штраф.
- **Полиция** — за угон, наезды и тараны полицейских машин растёт розыск. Уходите из зоны видимости: звёзды начнут гаснуть. При нулевом здоровье вас задерживают и выписывают штраф.
- **Машина** — следите за прочностью. После сильных аварий автомобиль дымится и может взорваться. Выходите заранее.
- **Сохранение** — прогресс автоматически сохраняется в `localStorage`; в паузе можно сохранить вручную и продолжить с титульного экрана.

## Что внутри

```
black-russia/
├── index.html   — разметка игры, HUD и экраны
├── style.css    — оформление, адаптив и мобильное управление
├── game.js      — игровой движок и вся логика
└── README.md
```

Технологии: HTML5 Canvas, ванильный JavaScript и CSS. Без сборщиков, зависимостей и внешних ресурсов — все файлы лежат в папке игры.

## Особенности

- процедурно генерируемый ночной город с дорогами, кварталами, парковками и неоновыми вывесками;
- пешеходы, трафик, парковка, угон и такси;
- розыск, полицейские погони, здоровье и броня;
- повреждения и взрывы машин, денежные пикапы;
- день/ночь, свет фар, частицы и звук через Web Audio API;
- отдельный сенсорный интерфейс для телефонов и планшетов;
- сохранение прогресса в браузере.
